═══════════════════════════════════════════════════════════════════════════
                    🌐 API METHOD (If Server Running)
═══════════════════════════════════════════════════════════════════════════

1. Add PDFs to data/ folder

2. Trigger indexing via API:
   
   curl -X POST http://127.0.0.1:8000/api/v1/index

3. Verify:
   
   curl http://127.0.0.1:8000/api/v1/database

═══════════════════════════════════════════════════════════════════════════
                    🔄 CLEAR DATABASE (Start Fresh)
═══════════════════════════════════════════════════════════════════════════

Option 1: Via Script
   python reset_database.py

Option 2: Via API
   curl -X DELETE http://127.0.0.1:8000/api/v1/database

After clearing, re-index all documents:
   python index_documents.py

═══════════════════════════════════════════════════════════════════════════
                    📁 SUPPORTED FILES
═══════════════════════════════════════════════════════════════════════════

✅ Supported: PDF files (.pdf)
❌ Not supported: Word docs, Excel, images, etc.

Note: PDFs must contain extractable text (not scanned images).

═══════════════════════════════════════════════════════════════════════════
                    💡 TIPS
═══════════════════════════════════════════════════════════════════════════

• Keep PDFs organized in data/ folder
• Index after adding multiple files (more efficient)
• First indexing takes longer (loading models)
• Subsequent indexing is faster
• Clear database if you want to start fresh
• Check logs if indexing fails: logs/application.log
